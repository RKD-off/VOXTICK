# VOXTICK

VOXTICK — программа для работы с демками CS2 из FACEIT и матчмейкинга. В ней можно посмотреть чат матча, послушать записанные голоса игроков и разобрать раунды на 2D-карте.
В чате можно выбрать сообщения конкретного игрока, скопировать текст или сделать скриншоты. Это удобно, например, для подготовки репорта на FACEIT.
Голосовой чат можно извлечь из демки и прослушать отдельно: переговоры своей команды, общение противников или их реакцию после удачного момента. Нужные записи можно сохранить в аудиофайл.
В 2D-демо отображаются позиции и перемещения игроков, стрельба, гранаты и события раунда. Можно быстро найти эпизод и посмотреть, что происходило на карте.
Также есть калькулятор игроков: выбираешь, чьи голоса нужны, а программа подготавливает команды для консоли. Их можно скопировать вручную либо автоматически открыть демку в CS2 и применить.

[Последний выпуск](https://github.com/RKD-off/VOXTICK/releases/latest)

Скачай установщик VOXTICK-Setup.exe и обнови его.

Для встроенного интерфейса нужен Microsoft Edge WebView2 Runtime.

Начиная с 4.2.35 приложение проверяет этот репозиторий автоматически.
При появлении новой версии внизу боковой панели появится «Доступно обновление».
Скачивание и установка запускаются по кнопке. Сохраняется резервная копия EXE.
